Heating System Optimization Using a Genetic Algorithm
Overview

This project uses a genetic algorithm (GA) to optimize residential heating system configurations. Each candidate solution represents a heating system with different characteristics, and the algorithm searches for the configuration that minimizes a fitness function based on energy consumption, operating cost, and occupant comfort.

The project was developed as part of an Artificial Intelligence laboratory assignment to demonstrate the use of population-based optimization techniques.

Features:
Genetic algorithm optimization   
Heating system simulation using one year of weather data  

Fitness evaluation based on:
Energy consumption  
Operating cost  
Comfort penalty  
Population diversity analysis  
Convergence visualization     
CSV export of fitness history  
Comparison between unconstrained and constrained optimization  

Heating System Representation

Each solution contains the following parameters:

House Size:	Small, Medium, Large <br>
Insulation Quality:	Poor, Normal, Good <br>
Heating Type:	Oil, Electric, Pellets, Geothermal <br>
Target Temperature:	16–22 °C <br>
Control Strategy:	Normal, Aggressive, Energy Saver <br>

Genetic Algorithm

The algorithm performs the following steps:

Generate a random population. <br>
Evaluate each solution using the fitness function. <br>
Select parents using tournament selection. <br>
Produce offspring through crossover. <br>
Apply mutation to introduce variation. <br>
Repeat for a specified number of generations. <br>
Return the best solution found. <br>

Fitness Function:

The objective is to minimize

Energy consumption <br>
Heating cost <br>
Comfort penalty <br>

The fitness function is calculated as

Fitness =
(energy weight × energy)
+ (cost weight × cost)
+ (comfort weight × comfort penalty)

Lower fitness values represent better heating system configurations.

Simulation Model:

The simulator models indoor temperature over an entire year using hourly outdoor temperatures.

Each hour the simulator:

Calculates heat loss based on house size and insulation. <br>
Determines whether heating should turn on. <br>
Applies heat generated by the selected heating system. <br>
Updates indoor temperature. <br>
Records energy usage. <br>
Calculates a comfort penalty based on temperature deviation from the target temperature. <br>

Output:

Best fitness history <br>

Running the Project:

Install the required libraries:

pip install pandas matplotlib

Run the optimization:

python GA_Unconstrained.py

or

python GA_Constrained.py

To compare both versions:

python GA_Comparison.py

The constrained version introduces symbolic knowledge into the optimization process by enforcing realistic constraints on heating system configurations.

Examples include restricting incompatible combinations of:

heating type  <br>
control strategy <br>
insulation quality <br>
house size <br>
target temperature <br>

Invalid solutions are rejected before entering the population.

Results:

The unconstrained algorithm explores the full search space and typically converges toward a highly optimized configuration.

The constrained algorithm searches a smaller, more realistic solution space. While the best fitness value may be slightly worse, the resulting heating systems are more practical and satisfy predefined real-world constraints.

Comparing both versions demonstrates how constraints affect:

convergence speed <br>
search space size <br>
population diversity <br>
optimization performance <br>
realism of the final solutions <br>
